# Frontend JobDating

React 19, TypeScript, Vite, Tailwind CSS 4 et React Router 7. Une seule page technique, sans fonctionnalité métier ni appel API.

Depuis frontend/ avec Node 24 (version utilisée localement) :

```powershell
npm.cmd ci
npm.cmd run dev
```

Vite affiche l'adresse locale. Démarrer Laravel dans un terminal séparé. Aucun parcours d'authentification ni échange avec le backend n'est encore implémenté.

Contrôles : `npm.cmd run lint` et `npm.cmd run build`. Le build inclut la vérification TypeScript.

Documentation officielle : https://vite.dev/guide/ et https://tailwindcss.com/docs/installation/using-vite
