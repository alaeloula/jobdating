# Erreurs connues à corriger

Défauts **rares**, reproduits par une revue, que le responsable technique a choisi de reporter (décision du 17/11/2026). Un défaut n'est noté ici **que s'il n'a aucun impact sur les développements suivants** ; sinon il est corrigé tout de suite.

Ils seront tous traités par la tâche **T-49**, avant la recette (`docs/BACKLOG.md`, semaine 6).

Pour les revues : ces cas sont **connus et acceptés** ; ne les signaler à nouveau que si un nouveau développement les aggrave ou les rend plus fréquents.
